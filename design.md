# Rancangan Antarmuka — Ruang Tumbuh

## Arah Produk

Ruang Tumbuh adalah pendamping refleksi dan perawatan diri yang **lokal lebih dahulu**. Refleksi, latihan, check-in tubuh, rutinitas, dan catatan makan disimpan pada perangkat sehingga fungsi inti tetap tersedia tanpa jaringan. Aplikasi dirancang untuk layar potret 9:16, penggunaan satu tangan, dan pola navigasi iOS yang familiar.

## Daftar Layar

| Layar | Konten dan fungsi |
|---|---|
| Beranda | Ringkasan catatan, latihan aktif, rutinitas, serta pintasan check-in dan refleksi. |
| Catat Refleksi | Fakta kejadian, emosi, dampak, tanggung jawab, pelajaran, dan eksperimen kecil. |
| Refleksi dan Detail | Daftar/filter catatan lokal serta pembacaan kembali satu refleksi. |
| Latihan | Status berhasil, sebagian, atau belum untuk eksperimen perilaku harian. |
| Kesehatan | Check-in tubuh, rutinitas personal, catatan makan, dan target opsional. |
| Tinjauan dan Pengaturan | Ringkasan tujuh hari, cadangan teks, impor, serta penghapusan data lokal. |

## Alur Utama

| Alur | Tahapan |
|---|---|
| Refleksi | Beranda → Catat refleksi → isi fakta dan pelajaran → simpan → lihat detail atau latihan. |
| Latihan | Tab Latihan → pilih hasil eksperimen → status disimpan lokal. |
| Perawatan diri | Tab Kesehatan → check-in/rutinitas/makan → simpan → Beranda dan Tinjauan diperbarui. |
| Cadangan | Tinjauan → Pengaturan → bagikan JSON atau tempel cadangan untuk memulihkan data. |
